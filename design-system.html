MUI mapping

Design system

Tokens and components for the admin redesign. Built to map 1:1 onto MUI v5, so each piece here has a known home in src/@core/theme. Two themes (gold, blue), two modes (light, dark).

60 / 30 / 10

60% white and background, 30% ink for text and labels. 10% brand: the active nav pill, main buttons, badges, and chart accents.

Borders, not shadows

No shadows anywhere. Depth comes from a 1px border and the canvas vs. surface step. Focus uses an outline.

Tokens only

Components use semantic roles like --text-muted. Hex values live in one file, so a theme swap is one attribute.

One bold moment

Each screen gets one loud element (on the dashboard, the brand-colored profit tile). Everything else stays quiet.

Charts

Series 1 is always the brand color. Solid 1px grid, 2px lines, a 10% area only on the lead series, columns up to 16px with a 4px rounded end. Every chart has a legend, a hover tooltip, and a table view. Palette checked for color-blind safety in both themes and modes.
